# Skills de Planejamento e Decoração de Casamento no GitHub

Pesquisa feita em 02/11/2026 na busca de código do GitHub (arquivos `SKILL.md` e repositórios).
Volume encontrado: cerca de 4.100 arquivos `SKILL.md` citando "wedding", 668 citando "casamento" e cerca de 970 citando "wedding decor". A maior parte é cópia (espelhos, coleções e registros que copiam as mesmas skills). Abaixo estão as skills **originais e relevantes**, já sem duplicatas.

Para instalar no Claude Code, copie a pasta da skill (a que contém o `SKILL.md`) para `~/.claude/skills/<nome-da-skill>/`.

## Recomendações

- **Planejamento:** `clawic/skills/wedding-planner` + `mohitagw15856` (`wedding-budget` e `wedding-logistics-planner`) + `FerroxLabs/murage/wedding-planner`.
- **Decoração:** `wonsukchoi/floral-designer` (custo e logística das flores) + `theneoai/florist` (decoração de eventos). **Não existe uma skill dedicada só à decoração de casamento** (temas, paletas, cenografia, mesas). É uma lacuna que vale a pena preencher com uma skill própria.
- **Em português:** só existem skills de marketing e jurídicas. Para o planejamento, o pacote mexicano `elimorals/Skills_MX/wedding-mx` é o mais fácil de adaptar.

> Atenção: o repositório `lxyeternal/MalSkillBench` (skill `book-wedding`) é um conjunto de dados de pesquisa sobre skills maliciosas. Não instale skills de lá nem de registros que só copiam conteúdo sem verificação. Leia sempre o `SKILL.md` e os scripts antes de instalar.
