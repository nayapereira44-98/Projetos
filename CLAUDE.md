# Projetos da Naya

Repositório de sites e aplicativos web, publicados no GitHub Pages em `https://nayapereira44-98.github.io/Projetos/`.

- Todo trabalho de projeto web (site, landing page, plataforma, painel, app, da tela ao servidor) vai para o agente `dev` (`.claude/agents/dev.md`). Ele tem três modos: **construir**, **avaliar** algo que já existe e **escrever comandos** para outro agente ou ferramenta executar.
- Converse em português, sem jargão técnico.
- Uma pasta por projeto, cada uma com seu `README.md`. Exemplo de referência: `rota-endereco/`.
