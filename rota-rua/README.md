# Rota Rua

App simples para a rua, feito em 07/11. O Rota Certa (`rota-endereco/`) ficou em espera.

- **Rota pelo endereço:** todos os números da mesma rua juntos, rua por rua, começando pela rua mais perto de você (GPS). A ordem é montada uma vez e fica fixa. "Refazer a rota a partir de onde estou" recalcula só o que falta.
- **Comércio / Apto / Casa:** o app separa pelo complemento do endereço (loja, sala, clínica, farmácia… / apto, bloco, edifício, número depois do número da casa…). Referências como "ao lado de" ou "próximo ao" não contam. Tocar no selo troca o tipo. Os filtros no topo mostram só um tipo, na mesma ordem da rota.
- **Bipar:** câmera aberta, aponte para a etiqueta. Apita e mostra Parada, tipo, posição na rota e os outros números da mesma rua, com o botão "Entreguei este endereço".
- Subir a mesma planilha de novo mantém a ordem e o que já foi entregue.
